# Баг-репорт 

**Заголовок**
 Ошибка авторизации с валидными данными 

**Шаги воспроизведения**
1. Открыть страницу входа: *`https://example.com/login`*
2. Ввести логин: *`testuser@example.com/login`*
3. Ввести пароль: *`qwerty123`*
4. Нажать кнопку **"Войти"**

**Итоговый результат:** Отображается сообщение об ошибке `Неверный логин и пароль`

**Ожидаемый результат:** Пользователь успешно авторизуется и переходит на главную страницу
